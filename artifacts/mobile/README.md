# Подход — модель данных

Приложение работает офлайн. Источник данных — локальное хранилище устройства; сервер и подключение к залу не нужны.

## Схема резервной копии JSON

- `Exercise`: справочная запись упражнения: стабильный `id`, название, группа мышц, целевая мышца, оборудование, тип движения, три шага техники и предупреждение по безопасности. Каталог поставляется вместе с приложением и содержит 50 упражнений.
- `WorkoutPlan`: готовая программа с категорией, уровнем, рекомендуемым отдыхом и массивом предписаний `{ exerciseId, sets, reps }`.
- `WorkoutSession`: сохранённая тренировка с временем начала/окончания, упражнениями, завершёнными подходами и тоннажом.
- `ActiveWorkout`: незавершённая сессия, сохраняемая после каждого изменения, включая текущий таймер отдыха.
- `SetEntry`: вес, повторения, состояние выполнения и подсказка результата предыдущей тренировки.

Карточка упражнения принимает необязательное поле `animation`: `format: "lottie"` с JSON-объектом или путём к JSON для iOS/Android, `format: "gif"` с URI или `format: "svg"` с SVG-разметкой. Если медиа ещё нет, включается зацикленная анимированная заглушка, а целевая мышца выделена акцентом.

Экспорт содержит версию формата, дату выгрузки, активную тренировку, историю, сохранённые планы и время отдыха. Импорт проверяет версию и базовую структуру до замены данных. Схема локального JSON соответствует сущностям, которые при необходимости можно перенести в таблицы `exercises`, `workout_plans`, `workout_sessions` и `workout_sets` PostgreSQL.

## Формат данных

На устройстве хранится один версионируемый объект:

```json
{
  "version": 1,
  "exportedAt": "2026-11-12T12:00:00.000Z",
  "activeWorkout": null,
  "workouts": [],
  "savedPlanIds": [],
  "restSeconds": 75
}
```

Запись упражнения включает `id`, `name`, `group`, `target`, `equipment`, `movement`, `summary`, `steps` (три пункта), `safety` и необязательное `animation`. Программа содержит `id`, `title`, `category`, `level`, `summary`, `restSeconds` и `exercises: [{ exerciseId, sets, reps }]`. Сессия хранит `id`, `name`, `startedAt`, `completedAt`, `tonnage` и список упражнений с подходами `{ id, exerciseId, name, sets: [{ id, weight, reps, completed, previousLabel }] }`.

Для PostgreSQL эти данные раскладываются на `exercises` (инструкции и анимация в JSONB), `workout_plans`, `workout_plan_items`, `workout_sessions` и `workout_sets`. Элементы плана и подходы связываются внешними ключами; номер и рекомендуемые повторения остаются отдельными полями строки.
