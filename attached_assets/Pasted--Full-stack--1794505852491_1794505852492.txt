# Роль и цель
Ты — ведущий продуктовый архитектор и Full-stack разработчик фитнес-приложений. Твоя задача — спроектировать и написать код интерактивного мобильного веб-приложения (PWA) для трекинга силовых тренировок в тренажерном зале. Приложение должно иметь интуитивный, контрастный интерфейс (темная тема по умолчанию для удобства в зале), быстрый отклик и продуманную архитектуру базы данных.

# Основной функционал

## 1. База упражнений (Exercise Library)
- **Наполнение:** Создай начальную базу минимум из 40–50 популярных упражнений, распределенных по группам мышц: Грудь, Спина, Ноги (квадрицепсы, бицепс бедра, ягодицы, икры), Плечи, Руки (бицепс, трицепс), Пресс/Кор.
- **Поиск и фильтрация:** Мгновенный поиск по названию, фильтрация по целевой группе мышц и типу оборудования (штанга, гантели, тренажеры, собственный вес, блоки).
- **Карточка упражнения:**
  - **Визуализация:** Зацикленная анимация выполнения упражнения (поддержка форматов Lottie JSON / GIF / SVG-анимации с подсветкой работающих мышц и заглушками для легкой замены медиафайлов).
  - **Техника выполнения:** Краткая пошаговая инструкция (3–4 пункта: исходное положение, фаза усилия, фаза возврата).
  - **Техника безопасности (Важно!):** Выделенный блок с ключевыми правилами безопасности (положение спины, суставов, дыхание, частые ошибки во избежание травм).

## 2. Конструктор и трекер текущей тренировки (Active Workout)
- **Свободный режим («Пустая тренировка»):** Пользователь приходит в зал, нажимает «Начать тренировку», добавляет упражнения из каталога через поиск или фильтры.
- **Логирование подходов:** Для каждого упражнения отображается таблица подходов:
  - Номер подхода.
  - Предыдущий результат (подсказка из прошлой тренировки, например: «60 кг × 10»).
  - Поля ввода: Вес (кг) и Повторения (раз).
  - Чекбокс выполнения подхода (при нажатии автоматически запускается настраиваемый таймер отдыха, например, 60–90 сек).
- **Завершение и сохранение:** Кнопка «Завершить тренировку» сохраняет сессию в историю, подсчитывает общий тоннаж (объем), длительность тренировки и фиксирует новые личные рекорды (PR).

## 3. Готовые программы тренировок (Workout Templates)
- Раздел для тех, кто не знает, что делать в зале, с возможностью запустить тренировку в один клик или скопировать в свой план.
- **Категории готовых комплексов:**
  - **Full Body (Все тело):** 3 базовых комплекса для новичков и среднего уровня.
  - **Upper / Lower (Верх / Низ):** Сбалансированные сплиты на верхнюю и нижнюю части тела.
  - **Акцентные тренировки (Push / Pull / Legs и специализации):** Отдельные готовые комплексы на «Руки и плечи», «Ноги и ягодицы», «Грудь и спина».
- В каждом готовом комплексе указаны рекомендуемое количество подходов, диапазон повторений (например, 3×10–12) и время отдыха.

## 4. Аналитика и отслеживание прогресса (Progress & History)
- **История тренировок:** Календарь и лента завершенных тренировок с возможностью посмотреть детали каждого дня.
- **Графики прогресса:** Визуализация роста рабочих весов и общего тоннажа по каждому конкретному упражнению за выбранный период (неделя, месяц, год).
- **Личные рекорды:** Автоматический расчет одноповторного максимума (1RM) по формуле Эпли и отметка о побитии рекорда.

# Требования к UI/UX и архитектуре
- **Дизайн:** Mobile-first (адаптация под экран смартфона), крупные кнопки и поля ввода (удобно нажимать одной рукой между подходами), высокая контрастность.
- **Хранение данных:** Используй локальное хранилище (LocalStorage / IndexedDB) для мгновенной работы без интернета в зале с возможностью экспорта/импорта бэкапа в JSON (или подготовь схему БД для Supabase/PostgreSQL).
- **Стек технологий (рекомендуемый):** React (или Next.js), TypeScript, Tailwind CSS, Lucide Icons, Recharts (для графиков).
